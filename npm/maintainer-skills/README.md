# @rstackjs/maintainer-skills

Contribution workflows for Rstack maintainers, including pull requests, documentation, and release notes.

Install with pnpm 12.11.0 or later:

```bash
pnpm add -D @rstackjs/maintainer-skills
pnpm approve
```

Choose the skills and agent directories for your project. See [Rstack contribution workflows](https://github.com/rstackjs/agent-skills#contribution-workflow-skills) for the available skills.
