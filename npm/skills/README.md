# @rstackjs/skills

Agent skills for developing, debugging, and upgrading Rstack projects.

Install with pnpm 12.11.0 or later:

```bash
pnpm add -D @rstackjs/skills
pnpm approve
```

Choose the skills and agent directories for your project. See [Rstack agent skills](https://github.com/rstackjs/agent-skills#usage) for the available skills.
